# Poussins Pythagorés (Node.js version)

## Overview
This repository contains a **Progressive Web App** for CP maths, now served via a lightweight **Node.js + Express** backend. The app works as a normal static PWA, but the server makes it easier to extend (add APIs, authentication, database, etc.).

## Project Structure
```
appjuli/
├─ public/            # (optional) place CSS/JS/images here if you later split them out
├─ index.html        # main PWA entry point (unchanged)
├─ server.js         # Express server
├─ package.json      # npm manifest
└─ README.md         # this file
```

## Setup & Run
```bash
# 1. Install dependencies
npm install

# 2. Start the dev server (http://localhost:3000)
npm run dev   # or npm start
```

The server serves `index.html` and any static assets. You can still "Add to Home Screen" on mobile browsers because the manifest and service‑worker remain embedded.

## Extending the App
- Add API routes under `server.js`.
- Move inline CSS/JS into `public/css/` and `public/js/` for better maintainability.
- Use the existing roadmap to plan new features (e.g., parents dashboard, audio narration, etc.).
